admin.slug_rules_help
Map one non-ASCII character to lowercase Latin letters, digits or hyphens. An empty replacement removes the character. Saved rules apply to newly generated addresses.
Zastąp pojedynczy znak spoza ASCII małymi literami łacińskimi, cyframi lub łącznikami. Pusta zamiana pomija znak. Zapisane reguły dotyczą nowo tworzonych adresów.
Укажите замену для одного символа вне ASCII. В замене допустимы строчные латинские буквы, цифры и дефисы. Пустая замена пропускает символ. Сохранённые правила применяются к новым адресам.
ASCII-ден тыс бір таңбаны кіші латын әріптерімен, цифрлармен не дефистермен алмастырыңыз. Бос алмастыру таңбаны өткізіп жібереді. Сақталған ережелер жаңадан жасалған мекенжайларға қолданылады.
