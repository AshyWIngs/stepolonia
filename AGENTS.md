# Repository instructions

- Use English for engineering prose in this repository, including documentation, source comments, diagnostics, branch names, commits, and pull requests. Russian engineering documentation belongs in the private documentation repository.
- Preserve localized product copy and native language names. Use English (`en`), Russian (`ru`), Polish (`pl`), or Kazakh (`kk`) in examples. Use Polish for the default demo. Tests may use additional languages when they exercise language import, fallback, or validation.
- Keep generated artifacts in sync with their sources. Use the repository commands to regenerate OpenAPI and SDK types. Preserve checked-in third-party assets byte-for-byte.
